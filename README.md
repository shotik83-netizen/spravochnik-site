# Справочник БиФК

Предыдущая версия страницы и данных перенесена в ветку `backup/2026-10-01`.

## Два файла

| Файл | Назначение |
| --- | --- |
| `index.html` | Приложение со встроенными стилями, скриптами, иконками и текстовым начертанием «СИБУР» |
| `bifk-data.txt` | Разделы, подразделы, записи, подписи шапки и настройки показателей |

Отдельный `config.json` не нужен. Настройки находятся в поле `config` внутри `bifk-data.txt`. Формат записей с четырьмя текстовыми полями сохранён. Старые базы без `config` читаются с начальными настройками.

## Подключение и SharePoint

Разместите оба файла в одной папке. Если база лежит отдельно, в HTML измените единственную начальную ссылку:

```js
const DATA_FILE_URL = './bifk-data.txt';
```

Укажите прямой относительный путь или HTTPS-ссылку на доступный файл. Относительные пути считаются от страницы приложения. При отдельном домене он должен разрешать чтение из браузера. При необходимости SharePoint использует принятое на площадке расширение `.aspx` для страницы.

В «Администрировании» задаются интервал, источники, видимость показателей, ставка с датой проверки и погодные информеры. При смене источника проверяются база и настройки до изменения страницы. Для постоянной смены расположения базы начальную ссылку меняют в HTML.

## Сохранение

«Сохранить изменения» в редакторе или администрировании скачивает один `bifk-data.txt` с настройками и всей базой. Настройка показателей сохраняет ранее подтверждённые изменения записей. При завершении без изменений файл не скачивается. Отмена редактора восстанавливает записи и все подписи шапки.

Скачанный файл пользователь вручную заменяет на SharePoint. Приложение не записывает файлы на сервер и не использует localStorage, sessionStorage, IndexedDB, cookies или service worker.

В шапке редактируются верхняя подпись, название подразделения и расшифровка; «СИБУР» фиксирован. Подписи сохраняются в `branding.label`, `branding.department`, `branding.description`. Отступы между шапкой, показателями и контентом — 12 px на компьютере, 9 px на планшете и 6 px на узком экране. Меню плавно расширяется в редакторе; на узком экране длинная строка доступна горизонтальной прокруткой. Нажатие вне администрирования закрывает окно.

## Поиск

- Обычный поиск: по названию, описанию, статусу, разделу и подразделу, по подстроке (набор по буквам).
- ИИ-поиск: запрос на естественном языке переводится моделью GLM (BigModel, `open.bigmodel.cn`) в условия отбора по названию, описанию, статусу, разделу и подразделу. Отбор записей выполняется в браузере; модель не видит сами записи и ссылки — ей передаются только текст запроса и списки известных статусов, разделов и подразделов. Режим переключается кнопкой «ИИ» у поля поиска; запрос выполняется по Enter или кнопке запуска.
- ИИ-агент открывается кнопкой в шапке. В диалоге он ищет документы по вопросу пользователя, показывает реальные совпадения из загруженного справочника, их разделы, статусы и рабочие ссылки. При большом числе совпадений их можно открыть в полном списке поиска. Переписка живёт только на открытой странице и при перезагрузке исчезает.
- Подключение общее для поиска и агента: «Администрирование» → «ИИ-поиск и агент». Поля совместимы с `aiSearch` в «Баланс-дашборде»: HTTPS-адрес API, модель и ключ Bearer. Для прокси на том же сайте допускается подключение без ключа с авторизацией сайта. Кнопка «Подключить» скачивает обновлённый `bifk-data.txt` только при изменении настроек; «Забыть ключ» скачивает файл при удалении ключа. Для публичного GitHub Pages параметры доступа оставлены пустыми — ключ из корпоративного баланса в репозитории отсутствует.
- Файл с рабочим API-ключом следует размещать только на защищённом SharePoint. Не публикуйте его в открытом GitHub. Запросы идут напрямую из браузера пользователя; сервис API должен быть доступен из его сети и разрешать запросы со страницы.

## Показатели

- USD/EUR/CNY: cbr-xml-daily.ru, JSONP с резервным JSON-запросом; два знака после запятой и дата источника. Интервал 15–1440 минут, по умолчанию 60. Скрытая вкладка пропускает обновление.
- Ставка: ссылка на официальную таблицу `https://www.cbr.ru/hd_base/KeyRate/`. Значение 14,00 % проверено за 30.09.2026. Это ручной снимок с датой; автоматической загрузки ставки нет. При изменении значения обязательна дата проверки; пустое значение оставляет ссылку на ЦБ.
- Погода: светлые изображения-информеры rp5 для Нижнекамска и Москвы. При ошибке изображения остаётся ссылка на прогноз. Источники показателей — HTTPS на доменах .ru.

## Проверка

Проверены синтаксис JavaScript, загрузка настроек и базы одним запросом, сохранение и повторная загрузка объединённого файла, отсутствие скачивания при отмене и сохранении без изменений, сохранение изменённых записей при настройке показателей, совместимость старой базы и сохранение предыдущего состояния при неверной базе, неверных настройках и недоступном источнике.
